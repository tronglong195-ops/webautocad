## 📖 Tính Năng Nổi Bật

1. **Thư Viện 184 Lệnh AutoCAD Toàn Diện**:
   - Phân loại rõ ràng: Vẽ 2D (Draw), Hiệu chỉnh (Modify), Kích thước & Chữ (Dim/Text), Layer & Thuộc tính, Block & Xref, Mô hình 3D (3D Solid), Hiển thị & In ấn, Đo đạc & Tra cứu (Inquiry), Quản lý & Tệp (Manage).
   - Từng lệnh có sơ đồ hình học SVG, cú pháp Command Line, tùy chọn phụ và mẹo thực chiến (Pro Tips).
2. **CAD Interactive Viewport (Mô Phỏng Trực Quan Canvas)**:
   - Mô phỏng từng bước vẽ, điểm bắt dính (OSNAP) và dòng nhắc Command Line tương tác.
3. **Bản Đồ Phím Chức Năng F1–F12 & Biến Hệ Thống (System Variables)**:
   - Khắc phục các lỗi kinh điển: mất hộp thoại lưu file (FILEDIA), chữ bị lộn ngược khi Mirror (MIRRTEXT), mất bảng chọn đối tượng (PICKFIRST, PICKADD), lỗi nét đứt bên Layout (PSLTSCALE), v.v.
4. **Interactive CAD Terminal Trainer (Luyện Gõ Lệnh)**:
   - Hệ thống đố vui luyện phản xạ gõ phím tắt (Alias) tính điểm và chuỗi đúng (Streak).
5. **Giao Diện Hiện Đại & Responsive**:
   - Chế độ Sáng / Tối (Dark/Light mode), tối ưu trên cả máy tính và điện thoại.
